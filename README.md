# CLASSROOT

A comprehensive, full-screen campus scheduling and navigation web application built for IIT Dharwad. CLASSROOT streamlines academic life by integrating department timetables, interactive campus maps, and real-time room availability into one centralized platform.

## Key Features

* **Smart Scheduling:** View and manage department-specific timetables and class slots.
* **Interactive Floor Maps:** Navigate campus facilities and locate specific classrooms effortlessly.
* **Room Booking & Capacity Search:** Search for available rooms based on seating capacity and current occupancy.
* **Role-Based Access:** Secure, tailored portals for both students and faculty members.
* **Event Announcements:** Stay updated with the latest campus events and academic notices.

## Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Authentication:** Google Sign-In OAuth
* **Data Management:** Local Storage for persistent session management
